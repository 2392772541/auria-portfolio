# 前后台功能对应审查（2026-09-09）

原页面经历多轮视觉迭代，部分新模块使用了静态文案和项目清单，旧后台无法编辑。此次保留现有视觉结构，增加统一页面内容模型和编辑器。

| 前台 | 后台入口 | 数据来源与修改方式 |
| --- | --- | --- |
| 首屏标题、签名、介绍、背景视频、轮播图 | 页面内容 → 首屏与轮播 | 编辑文本，上传/选择素材，关联作品，排序和显示 |
| 首页个人经历、照片、指标、职业路径 | 页面内容 → 个人经历 | 照片也供作品简介使用；业绩数字保留原样，需站长核实 |
| 首页 Demo 标题 | 页面内容 → Demo 展示标题 | 栏目标题与说明，首页显示开关 |
| 项目标题、分类、发布状态、封面、展示图片/视频、排序、背景、行动、成果、标签、入口文字 | 作品 | 已接入首页与详情；精选表示排序优先 |
| 视频章节、结果指标、Demo 链接、公开体验码、边界说明 | 页面内容 → Demo 章节与指标 | 关联作品ID；首页与作品页共用。作品视频优先，备用视频仅在无展示素材时使用 |
| 能力矩阵、其他亮点 | 页面内容 → 对应分区 | 首页与作品页同源，列表可增删、排序与隐藏 |
| 个人延伸、池塘入口 | 页面内容 → 个人延伸与池塘 | 站内作品、池塘或外部链接；标题/摘要留空跟随作品，图片可单独指定 |
| 个人优势 | 页面内容 → 个人优势 | 标题、说明、卡片、插画与标签 |
| Git 开源项目 | 页面内容 → 开源项目 | 独立清单，不与工作案例混合；封面可保持仓库固定路径 |
| 文章列表与正文 | 文章 | 草稿不公开；发布后列表和详情生效 |
| 关于/联系/文章页介绍、页脚合作方向与电话 | 页面内容 → 内页与联系文案 | 结构化文本字段 |
| 品牌名、个人定位、邮箱、地区 | 品牌与联系 | 页脚、内页与浏览器标题使用；首页设计标题单独配置 |
| 作品页个人简介、关于页经历、教育与技能、PDF | 个人简历 | 首页经历单独呈现，PDF本身仍需重新上传更新 |
| 数字分身开关、推荐问题、知识、固定问答 | 数字分身 | 现有流程保留，密钥仍只在服务器 |
| 联系表单提交 | 联系表单 | 服务端先入库；外部推送取决于服务器配置 |
| 图片/视频/PDF 上传与引用 | 媒体库 / 素材字段 | 新增页面内容引用保护，被引用素材不能删除 |

## 修复内容

- 新增 page_content 单行JSON表，保留旧作品、文章、简历和账号数据。默认内容迁移时绑定稳定作品ID，排序不改变指向。删除作品同步清理关联入口；草稿及对应元数据不进入公开API。
- 修复启动时自动覆写KOLPilot、补充示例作品/文章的问题。示例只在首次安装初始化；后台修改、草稿状态与删除操作在服务重启后保留。
- 移除固定项目素材对后台素材的覆盖，接通背景/成果/标签/入口文字，支持纵向与横向媒体适配。
- 修复公开作品仅1–2个时环形侧卡越界或重复，以及旧版 #showcase-project 链接未选中目标的问题。
- 编辑器支持列表增删排序、开关、素材选择/上传、未保存提示、保存失败保留编辑。新增条目留空，不复制旧项目的成果数值。
- 保存端验证类型、数量、链接协议、唯一标识、关联作品和章节秒数，接口沿用登录与CSRF保护。
- 池塘继续按需加载，卡片标题与弹层标题对应；PDF开关用组件边界避免条件Hook问题。
- 公开API加载失败显示重试界面；首页增加内页入口，避免开源页面没有明显入口。

## 运维与范围

- 本地服务为 Express/SQLite；遗留 Cloudflare Worker 不属于此次部署目标。迁移需同时携带 server/、shared/ 和 dist/client/。
- 「保存并发布页面内容」直接发布；没有新增多版本草稿、预发布审核与并发冲突合并系统。更换内容无需构建，修改交互代码仍需构建。
- 作品发布状态与栏目开关独立。隐藏栏目不删除内容。
- 开源项目维护固定外链；没有添加 GitHub 自动同步或账户密码管理界面。
- Git仅备份源码与公开资产；数据库和上传附件在本地单独备份。
